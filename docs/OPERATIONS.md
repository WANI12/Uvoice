# Operations and escalation notes

## Case workflow in this MVP

Report submitted → case created → case assigned by admin/supervisor → assigned responder records actions → responder updates status → admin/supervisor closes after review.

## Operational rules to configure before launch

- Duty roster and out-of-hours coverage.
- Named focal points and backup focal points for each response partner.
- Category-to-mandate routing matrix.
- Acknowledgement and response SLAs approved by each partner.
- Independent referral route when an allegation concerns the normal recipient.
- Survivor-centred and child safeguarding referral rules.
- Criteria for urgent safety escalation and public alert approval.
- Closure checklist, reopening process and reporter feedback policy.

The current MVP does not run an automatic SLA timer. A case must be monitored by the situation-room team until the escalation worker is implemented.
